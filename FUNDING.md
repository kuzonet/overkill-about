# Funding

`kuzonet/overkill-about` is free, open-source software released under the [MIT License](LICENSE.md).
It is built and maintained by [Kuzonet](https://github.com/kuzonet) in our own time.

If this plugin saves you time or is part of a product you ship, please consider supporting its
development.

## How to support

- **GitHub Sponsors:** [github.com/sponsors/kuzonet](https://github.com/sponsors/kuzonet)
- **Star the repository** on [GitHub](https://github.com/kuzonet/overkill-about). It helps other
  people find the plugin.
- **Contribute:** report bugs, suggest features or open a pull request. See
  [CONTRIBUTING.md](.github/CONTRIBUTING.md).

## How funds are used

Sponsorship pays for the time spent on:

- keeping the plugin compatible with new Filament, Laravel and PHP releases
- fixing bugs and answering issues
- writing documentation and tests
- adding new features

Thank you for your support!
